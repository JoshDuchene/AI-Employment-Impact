# AI Employment Impact

This project examines the relationship between exposure to artificial intelligence (AI) and changes in employment by industry in the United States.

## Research question

How is industry-level exposure to AI associated with changes in U.S. employment over time?

## Data

The analysis is intended to use U.S. Bureau of Labor Statistics (BLS) employment data and an industry-level measure of AI exposure. No source data has been added yet. See [`data/README.md`](data/README.md) for the expected input files and format.

## Findings

No findings are available yet; the data has not been collected or analyzed. The analysis notebook documents the planned workflow and will produce results once the input files are provided.

## Project structure

- `data/` — raw input data or links and notes about its sources
- `analysis.ipynb` — the research narrative and analysis workflow
- `results/` — generated figures and tables (created when the notebook is run)
